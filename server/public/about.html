Proje Hakkında

Alumni Tracker projesinin amacı, teknik altyapısı ve geliştirici bilgileri.

Proje Nedir?

Alumni Tracker, İstanbul Yeni Yüzyıl Üniversitesi Bilişim Sistemleri (YBS) bölümü Web Programlama dersi kapsamında geliştirilen tam kapsamlı bir mezun takip ve yönetim platformudur.

Platform, üniversitelerin mezunlarıyla bağlantılarını sürdürebilmelerini, kariyer gelişimlerini takip edebilmelerini ve etkin bir mezun ağı oluşturabilmelerini amaçlamaktadır. Mezunlar profillerini güncelleyebilir, burs fırsatlarını takip edebilir ve üniversite etkinliklerine katılabilirler.

Sistem, modern web teknolojileri ve Docker konteyner altyapısı kullanılarak geliştirilmektedir. Backend tarafında Node.js ve Express.js ile RESTful API, veritabanı olarak MongoDB kullanılmaktadır. Tüm uygulama Docker Compose ile tek komutla ayağa kaldırılabilmektedir.

🛠️ Kullanılan Teknolojiler

Projede kullanılan teknolojiler ve araçlar

🟢

Node.js

Sunucu tarafı JavaScript çalışma ortamı. Yüksek performanslı, olay tabanlı mimari.

⚡

Express.js

Hızlı ve minimal web framework. RESTful API geliştirmek için ideal.

🍃

MongoDB

Esnek NoSQL veritabanı. Mongoose ODM ile şema tabanlı veri modelleme.

⚛️

React.js

Bileşen tabanlı kullanıcı arayüzü kütüphanesi. Vite ile hızlı geliştirme.

🐳

Docker

Konteyner platformu. Docker Compose ile çoklu servis yönetimi.

🔐

JWT & bcrypt

Güvenli token tabanlı kimlik doğrulama ve şifre hashleme.
